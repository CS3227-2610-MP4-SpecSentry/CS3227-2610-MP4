One change, three accountable roles.

Each workspace exposes only the information and actions its role needs. Server-side authorization, lifecycle checks and immutable submitted revisions remain authoritative.

Contributor
Draft a change specification, submit immutable revisions, attach a unified text patch and respond to review findings. The Spec Draft Assistant offers bounded suggestions while manual drafting stays available.
Reviewer
Claim submitted work, assess requirement coverage, record findings and approve or request changes. The Patch Risk Assistant highlights risks and test ideas but never records a decision.
Release Maintainer
Assemble approved revisions, record exact-version smoke evidence, resolve deterministic blockers and publish an immutable release snapshot. The Release Gate Assistant remains advisory.

Test every role safely.

The same public demo identities are available in both isolated environments. Use production for grader testing and development for team testing.
