SpecSentry

Connect change specifications, human code review and release evidence in one workspace.

Development status — 25 October 2026: infrastructure and architecture scaffold. Role workflows and AI features are planned. No live application URL has been verified.

Planned workflows

Contributor

Prepare specifications, criteria and text patches. A Spec Draft Assistant will suggest ways to clarify requirements.

Reviewer

Assess submitted revisions, record findings and decide coverage. A Patch Risk Assistant will suggest gaps, risks and tests.

Release Maintainer

Assemble approved changes and verify release gates. A Release Gate Assistant will summarize readiness considerations.

AI is advisory. Human decisions and deterministic server checks control changes, approvals and publication. The planned application does not execute patches or deploy submitted code.
