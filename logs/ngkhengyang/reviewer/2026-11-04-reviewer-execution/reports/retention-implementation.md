## Scope and behavior

Implemented the settled [retention security contract](retention-design.md) in `PrismaAiAccounting.cleanup(deadline: AiDeadline): Promise<void>`. Existing `locked`/`bounded` helpers supply the single transaction, seeded quota coordinator lock, deadline enforcement, post-lock time capture, and expired-lease removal. The tagged SQL parent deletion uses correlated `NOT EXISTS` predicates for live leases and recent attempts. It preserves request/attempt starts and completions at or after the preceding 24-hour cutoff, including future timestamps, and deletes only parents at/past their existing retention expiry. Attempts cascade with the parent; expired orphan leases can be reclaimed while unexpired orphans remain.

The explicit `src/server/src/ai/cleanup-ai-records.ts` command loads environment configuration, validates only the required PostgreSQL URL, opens one database client, creates/closes the existing bounded request deadline, invokes the authority once, disconnects in `finally`, and emits fixed safe outcomes. It makes no provider calls and starts no Nest application. `docs/ai-retention.md` documents invocation and operational limitations.
