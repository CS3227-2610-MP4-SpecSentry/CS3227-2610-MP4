# Evaluation evidence

Store versioned product-AI cases/rubrics and actual experiment records here. Use
[the experiment template](../templates/EXPERIMENT.md) for development comparisons;
follow [AI security gates](../specs/AI-SECURITY-SPEC.md) for all three product assistants.

Each result must name its source revision, conditions, case IDs, command, observed
outcome and measurement source. Keep synthetic inputs and safe metadata only.
Planned cases are not executed evidence. No evaluation result is added by the
module initialization. Link completed evidence from
[traceability](../TRACEABILITY.md) and [Reflections](../../docs/Reflections.md).
